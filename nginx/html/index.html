WEEK 5 · CAPSTONE PROJECT

케어마켓(CareMarket)

건강 목표·영양 조건 기반 맞춤형 건강식품 쇼핑몰

누적 조회수 불러오는 중

caremarket.vercel.app ↗

프로젝트 소개

사용자가 건강 목표(근육량 증가 / 체중 관리 / 식단 영양 관리 / 영양제 탐색)와 보조조건(저당·저염·고단백·카페인 제외·알레르기 제외)을 고르면, 조건에 맞는 영양제·프로틴·웰니스 간편식을 추천하는 쇼핑몰입니다.

근육량 증가체중 관리식단 영양 관리영양제 탐색 저당저염고단백카페인 제외알레르기 제외

주요 기능

  • 자연어 검색 → 정형 조건 변환 — “단백질 많고 당 적은 간식” 같은 문장을 목표·보조조건 필터로 바꿔 검색합니다.
  • 장바구니 영양성분 실시간 합산·검증 — 담은 상품의 영양성분을 합산하고 선택한 조건을 벗어나는지 확인합니다.
  • 토스페이먼츠 테스트 결제 + 서버 재고 차감 — 결제 승인 후 서버에서 재고를 차감합니다.
  • 구매자·관리자 권한 분리 — 구매자는 쇼핑·주문, 관리자는 상품·재고·주문 관리를 담당합니다.

사용 기술

  • 프론트엔드: React · Vite · Tailwind CSS
  • 백엔드·DB: Supabase (PostgreSQL · Auth)
  • AI: Gemini API (자연어 검색 조건 변환)
  • 결제: Toss Payments (테스트 결제)
  • 배포: Vercel
